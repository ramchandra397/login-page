# Login Page

A responsive, professional login page built with HTML, CSS and JavaScript.

## Features
- Split-screen layout with branding panel
- Email and password validation with live error messages
- Show / hide password toggle
- Remember me (saved with localStorage)
- Loading spinner and success / error alerts
- Simulated Google and GitHub sign-in (front-end demo)
- Fully responsive for mobile and desktop

## Tech Stack
HTML5, CSS3, JavaScript (ES6), Font Awesome
